# Hi, I'm Joel

**Software Engineer building business systems, integrations, automation, and applied AI.**

My background started in customer operations and analytics, then moved into digital transformation and platform engineering. That shaped how I approach software: I care about architecture and code, but also about how systems behave when they meet real users, business processes, integrations, constraints, and production failures.

Today I work across backend services, APIs, enterprise platforms, automation, data, and applied AI — especially where multiple systems and operational workflows need to work together reliably.

## What I build

I'm most interested in software that connects business operations with engineering:

- **Business systems** that turn operational processes into reliable software workflows.
- **APIs and integrations** that connect platforms, services, data, and external systems.
- **Automation** that removes manual work without hiding important business rules.
- **Applied AI systems** that combine models with tools, APIs, structured data, guardrails, and deterministic software.

My work commonly involves Python and backend services, REST APIs, SQL and PostgreSQL, OAuth and identity, Salesforce and enterprise platforms, React/TypeScript interfaces, CI/CD, and production troubleshooting.

## How I work

I like working across the full path from problem to production:

**Discovery → Architecture → Implementation → Integration → Testing → Deployment → Operation**

That means understanding the workflow before automating it, defining system and API boundaries, implementing the solution, validating failure modes, and making sure the result can actually be operated and maintained.

I pay particular attention to authentication and authorization, integration contracts, observability, failure handling, least privilege, CI/CD, maintainability, and production behavior.

## Current focus

I'm deepening my work in **applied AI engineering**, particularly agentic systems that use models as one component of a larger software architecture.

My current focus includes tool use, retrieval and grounding, evaluation, observability, security boundaries, and AI workflows that can interact safely with real APIs and business systems.

It is a continuation of the same problem I've been working on throughout my career: **how to make complex operations work better through software.**
